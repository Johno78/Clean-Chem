Comfort PF Classic is a concentrated fabric softener for on-premise laundries, dosed straight into the washing machine's rinse-cycle drawer. All three variants — Fresh (Blue), Sensitive (Pure) and Sensorial (Pink) — use the same dosing; only the fragrance and skin-sensitivity profile differ.

Before you start

  • Dose into the machine drawer — don't pour directly onto fabrics.
  • Wash hands after handling.
  • For professional/trade use only.
  • Full safety information is in the product's Safety Data Sheet — ask us if you need a copy.

How to use it

Dose depends on the machine's load capacity — measure with the bottle cap or a dosing cup.

Machine wash

  1. For a 6–7kg machine, dose 55ml into the fabric conditioner drawer.
  2. For a 4–5kg machine, dose 35ml into the drawer.
  3. Run the wash as normal — the softener releases automatically during the rinse cycle.

Hand washing

  1. Dose 18ml per 10L of water.
  2. Add during the final rinse.
  3. Do not pour concentrate directly onto fabric.
