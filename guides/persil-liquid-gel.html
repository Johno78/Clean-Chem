Bio or Non-Biosame dosing

Persil Professional Liquid (with wash booster) is a laundry detergent giving 67 washes per bottle. Bio contains enzymes for strong stain removal; Non-Bio leaves them out for sensitive skin — both dose the same way, straight into the machine's dispenser drawer.

Before you start

  • Not suitable for silk or wool.
  • Always check garment care labels before washing.
  • Don't overload the washing machine — this reduces cleaning performance.
  • For professional/trade use only.
  • Full safety information is in the product's Safety Data Sheet — ask us if you need a copy.

How to use it

67 washes per bottle — a small dose covers a full load. Use the cap to measure.

Machine wash

  1. Check the garment care labels and choose an appropriate wash cycle and temperature.
  2. Add a dose of the liquid to the dispenser drawer (check the cap's fill line, or the dosing table on the bottle, for the exact amount).
  3. Increase slightly for heavily soiled loads or hard water.
  4. Run the wash as normal.
